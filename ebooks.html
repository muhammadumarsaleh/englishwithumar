Bagaimana cara menerima file setelah pembelian?

Setelah pembayaran dikonfirmasi via Lynk.id, Anda akan menerima email berisi tautan unduhan otomatis. Tautan berlaku selamanya dan bisa diunduh berulang.

Apakah file bisa dicetak berulang kali?

Ya. Lisensi berlaku untuk penggunaan pribadi / satu kelas. Untuk penggunaan sekolah dengan banyak kelas, silakan hubungi kami untuk lisensi institusi.

Metode pembayaran apa saja yang tersedia?

Semua metode yang tersedia di Lynk.id: transfer bank, e-wallet (GoPay, OVO, Dana, ShopeePay), QRIS, dan kartu kredit/debit.

Apakah ada garansi jika file rusak?

Tentu. Jika file tidak bisa dibuka atau rusak, hubungi kami di hello@edusparkstudio.id dan kami akan kirim ulang dalam 1x24 jam.
